# A/B Testi: Mobil Uygulama Abonelik Ekranı

### Proje Açıklaması
*  Mobil uygulamamızın kullanıcılarına, onboarding sürecinin ardından premium özelliklere erişim sağlayan haftalık 4.99 dolarlık bir abonelik satın almaları önerilmektedir. Mevcut tasarımda, bu ekranı gören kullanıcıların %17’si abonelik satın almaktadır.
* Yeni bir abonelik ekranı tasarımını test etmeye karar verdik. Bu alternatif ekranda yine 4.99 $ değerinde bir abonelik sunuyoruz, ancak kullanıcılara bunun %50 indirimli olduğu bilgisi veriliyor.
* Uygulama günlük olarak yaklaşık 2.000 kez indiriliyor ve bu kullanıcıların %34'ü abonelik ekranına ulaşıyor. Bu A/B testi ile, yeni tasarımın mevcut tasarıma kıyasla abonelik dönüşüm oranını nasıl etkilediğini analiz etmeyi amaçlıyoruz.
